Car Code Reader for Windows 11 (and Windows 10)
================================================

1. Unzip this folder anywhere you like (Desktop is fine).
2. Double-click "Car Code Reader.exe" to start it.

The first time you run it, Windows SmartScreen may show a blue
"Windows protected your PC" box because the app isn't from a big
publisher. This is normal for a small app. To run it:

   - Click "More info"
   - Click "Run anyway"

You only have to do that once.

Connecting to your car
----------------------
Plug your OBD-II adapter into the car's port, turn the key to ON,
then in the app choose Wi-Fi or Bluetooth and connect. For a USB
adapter, Windows installs the driver automatically the first time
you plug it in.

Nothing extra to install - Python is already built into the app.
